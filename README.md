# Dotfiles
Misc dotfiles. nvim, tmux and the `tm` sessionizer live in
[reeceomahoney/tm](https://github.com/reeceomahoney/tm):

   ```sh
   curl -fsSL https://raw.githubusercontent.com/reeceomahoney/tm/main/install.sh | sh
   ```

# Setup
   ```sh
   git clone git@github.com:reeceomahoney/.dotfiles.git ~/.dotfiles
   cd ~/.dotfiles
   sudo apt install stow
   stow .
   ```
